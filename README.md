## Under the hood

This is where the BBROSE storefront and its tooling are built.

<details>
<summary><b>The stack</b></summary>

<br>

| Layer | What we use |
|---|---|
| **Backend** | Django 4.2 · Python 3.12 · PostgreSQL |
| **Frontend** | Tailwind CSS (pre-compiled) · progressive enhancement, no SPA |
| **Serving** | Gunicorn · WhiteNoise |
| **Auth & comms** | django-allauth · Anymail · Twilio |
| **Intelligence** | Anthropic Claude — powers the on-site product assistant |

</details>

<details>
<summary><b>What we've built</b></summary>

<br>

- **Shade Finder** — undertone-driven shade matching across the full colour range
- **Virtual try-on** — live hair colour and nail polish preview in the browser
- **Lookbook** — editorial looks mapped to the products that create them
- **AI assistant** — finds the right product and navigates the site, by text or voice
- **Four languages** — English, العربية, Español, 中文 — with full RTL support

</details>
